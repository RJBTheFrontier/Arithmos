# Arithmos
**A modular arithmetic interpreter built from scratch in Python.**
Python - Educational Project - Pre-alpha

## Overview
Arithmos is a lightweight arithmetic interpreter built from scratch in Python! Instead of relying on Python's built-in eval(), it aims to implement its own lexer, parser, abstract syntax tree, and evaluator.

It is designed to evaluate mathematical expressions through a custom-built interpreter pipeline.

## Goals
- Build a modular arithmetic interpreter.
- Implement lexical analysis and tokenization.
- Develop a custom parser and AST.
- Support mathematical operator precedence, including parentheses.
- Make an interactive REPL.
- Explore fundamental concepts behind language design.

## Planned Features
- Basic arithmetic operations
- Floating-point numbers
- Operator precedence
- Parentheses support
- Unary operators
- Exponentiation
- Interactive REPL
- Variables and assignments
- Built-in mathematical functions
